BillBot 💸

**BillBot** is a full-stack expense tracking application that helps users log daily expenses, scan physical bills using OCR, and stay on top of upcoming dues — all from a live, real-time dashboard.

🔗 **Live Demo:** [https://bill-bot-phi.vercel.app/](https://bill-bot-phi.vercel.app/)

---

✨ Features

- 📊 **Expense Logging** — Add daily expenses with payment mode and timestamp
- 📸 **OCR Bill Scanning** — Photograph a paper bill or receipt and BillBot automatically reads and fills in the expense details (built with Python)
- ⏰ **Due Date Reminders** — Get notified ahead of upcoming bill due dates so you never miss a payment
- 📈 **Live Dashboard** — Every scanned or manually added expense updates the dashboard instantly for a real-time view of your spending
- 🔐 **Secure Data Handling** — Expense records are stored and managed through a MySQL-backed Spring Boot API
